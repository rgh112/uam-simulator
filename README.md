# UAM 학습 시뮬레이터

[시뮬레이터 실행](https://rgh112.github.io/uam-simulator/)

브라우저에서 두 기체의 3D 비행과 임무 선택 모델의 학습을 실행합니다. 설치나 로그인은 필요하지 않습니다. PC의 Chrome 또는 Edge를 권장합니다.

## 사용 방법

- **예제 비행 실행**: 20회 학습한 모델을 불러와 비행을 시작합니다. 현재 실험은 예제 설정으로 바뀝니다.
- **학습 시작**: 비행을 반복하면서 모델을 학습시킵니다.
- **학습 결과로 비행**: 현재까지 학습한 모델을 화면의 기체에 적용합니다. 적용할 모델은 5회 학습마다 갱신됩니다.
- **모델 저장 / 모델 불러오기**: 가중치와 학습 이력을 JSON 파일로 저장하거나 복원합니다. 새 에피소드부터 실행하며, 진행 중인 비행과 경험 재생 버퍼는 복원하지 않습니다.
- **이 설정으로 새로 시작**: 선택한 조건으로 비행과 학습을 초기화합니다.

## 실행 방식

GitHub Pages는 화면과 프로그램 파일을 제공합니다. 물리 계산과 학습은 접속한 기기의 브라우저에서 진행됩니다. GitHub 서버나 원격 GPU에서 학습하는 서비스가 아닙니다. 각 접속자의 실험은 독립적이며, 모델을 저장하지 않고 페이지를 닫으면 학습 상태가 사라집니다.

`index.html`을 내려받으면 인터넷 연결 없이 실행할 수도 있습니다. 실행 파일에 3D 엔진·물리 엔진·회로·예제 모델이 포함되어 있습니다.

## 사용한 회로와 모델

- 데이터: [공식 MaleCNS v1.0](https://male-cns.janelia.org/download/), CC-BY-4.0.
- 범위: 13개 타입의 **350뉴런 부분 회로**, 방향 연결 15,182개. 초파리 전체 뇌 모델은 아닙니다.
- 원본 ID와 연결 방향, 시냅스 수를 보존했습니다. 출처와 추출 조건은 [데이터 기록](data/connectome-manifest.json)에 있습니다.
- 실제 연결 구조를 사용하는 인공 순환 신경망이 점검 지점과 복귀를 선택합니다. 물리 비행에서 얻은 보상으로 학습합니다.
- 자세 안정화와 로터 제어기는 고정되어 있습니다. 생물학적 발화나 실기체 공력을 검증한 모델은 아닙니다.
- 뉴런 활동 그림은 타입별 개념 배치입니다. 표시하는 연결은 400개이며, 회로 계산에는 전체 15,182개 연결을 사용합니다.
- 내장 예제는 모방 없이 20회 보상 학습한 모델입니다. 분리된 검증 임무 3개를 완료했지만, 단일 시드의 동작 확인이며 커넥톰의 성능 우월성을 입증하지 않습니다.

## 배포

이 저장소는 웹 실행본만 포함합니다. `main` 브랜치의 루트 디렉터리를 GitHub Pages로 배포합니다. 업데이트할 때 `index.html`을 교체하면 새 버전이 배포됩니다.

Three.js, cannon-es, Noto Sans KR, MaleCNS의 저작권과 라이선스는 [외부 자료 이용 표시](THIRD_PARTY_NOTICES.txt)에 있습니다.
